# 01. 원작 게임 & 세계관 설정

> 가제: **「멸망까지 10년」** — 고인물이 망겜 속 엑스트라로 빙의했다

---

## 1. 원작 게임: 《에테르 크로니클》

| 항목 | 내용 |
|---|---|
| 장르 | 아카데미 육성 RPG + 연애 시뮬레이션, 멀티 엔딩 |
| 서비스 | 10년 차 고인물 게임. 신규 유저는 거의 없고 코어 유저만 남음 |
| 엔딩 수 | **37개. 전부 배드 엔딩 또는 노멀 엔딩** |
| 별명 | "모든 길이 멸망으로 통하는 게임", "에테크 = 에휴 테크트리" |
| 커뮤니티 논쟁 | "진엔딩은 없다" 파 vs "아직 못 찾았을 뿐" 파 |
| 개발사 | 스튜디오 망각(忘却). 마지막 패치 이후 연락 두절 |

**마지막 패치 노트의 한 줄**
> *"그 아이들을 모두 구할 수 있는 건, 이 세계 바깥의 누군가뿐입니다."*

### 나(플레이어)는 누구인가
- 플레이타임 3,000시간 이상. 37개 엔딩을 모두 본 고인물이자 공략 위키 편집자
- 진엔딩을 찾다가 지쳐서 마지막으로 게임을 켠 날, 눈을 떠보니 **게임 속 엑스트라**가 되어 있음
- 시점: **아카데미 입학 1개월 전**

### 원작 주인공의 상태
- 원작에서 주인공 **아렌**(기본 이름)은 플레이어가 조종하던 캐릭터였음
- 이제 아렌은 **플레이어 없이 스스로 움직이는 NPC**가 됨
- 원작에서 성격이 없던 캐릭터라, 이 세계에서 **어떤 성격으로 자라날지는 아무도 모름**
- 내가 아렌과 어떻게 엮이느냐에 따라 **아렌이 어느 루트로 갈지가 바뀜**

## 2. 왜 진엔딩이 없었나: 루트 상호배제

원작의 멸망 원인은 7개입니다. 하나의 루트로는 **최대 2~3개만** 막을 수 있어요.

| 원작 루트 | 막을 수 있는 것 | 반드시 터지는 것 | 이유 |
|---|---|---|---|
| **미라벨 루트** (마탑) | 차원문, 주인공 흑화 | 세계수, 내전 | 3학년 여름, 리아나 구출과 마탑 사건이 같은 주에 일어남 |
| **리아나 루트** (세계수) | 세계수, 봉인 약화 | 내전, 차원문 | 세계수 의식에 1년 동안 묶여서 제국 정세에 개입 불가 |
| **카이든 루트** (제국) | 내전 | 세계수, 차원문 | 황자 편에 서면 교회와 엘프가 적대 |
| **카엘 루트** (마족) | 마왕 (협상) | 내전 가속, 교회 적대 | 마족과 손잡은 것이 들통나 제국이 분열 |
| **솔로 루트** (전투 특화) | 마왕 (힘으로) | 나머지 전부 | 주인공은 최강이 되지만 동료가 전멸해서 흑화 |
| **하렘 루트** (전원 호감) | 없음 | 전부 동시에 | 모든 사건에 조금씩 개입하다가 아무것도 못 막음 |

> **결론:** 주인공은 한 명이고 몸도 하나다. 같은 시기에 터지는 사건을 동시에 막는 것은 **원작 시스템상 불가능**했다.
> 하지만 지금은 **시스템 바깥의 변수, 즉 내가 있다.**
> 주인공이 하나의 루트를 맡고, **나와 내가 키운 동료들이 나머지 사건을 맡는다.** 이것이 진엔딩의 조건이다.

## 3. 세계관

### 대륙 아스테라
| 세력 | 설명 | 아카데미와의 관계 |
|---|---|---|
| **아스테라 제국** | 대륙 중앙의 인간 제국. 늙은 황제와 황자 셋 | 아카데미 설립자이자 최대 후원자 |
| **실바니엘 숲** | 세계수 '유그드'를 지키는 엘프 왕국 | 교환학생 파견 |
| **성교회** | 빛의 여신을 섬김. 성검과 용사 선정을 관리 | 신성과 운영 |
| **마탑 연합** | 마법사들의 자치 도시 | 마도과 교수진 파견 |
| **잿빛 장벽** | 마계와 인간계 사이의 거대한 결계 | 졸업생 대부분이 배치되는 전선 |
| **마계** | 봉인된 마왕과 마족들의 땅 | 공식적으로는 적 |

### 왕립 루미에르 아카데미
- 4년제. 매년 약 200명 입학, 졸업 시 절반 정도만 남음
- **학과:** 기사과 / 마도과 / 신성과 / 레인저과 / 연금과 (2학년부터 전공 선택)
- **반 배정:** 입학 시험 성적순으로 S / A / B / C / D반. 원작 주인공은 B반, 나는 **D반**에서 시작
- 학교 지하에 **훈련용 미궁**이 있는데, 깊은 층은 아무도 끝까지 내려가지 못했음

### 역사: 천 년 전의 봉인
- 천 년 전, 초대 용사가 성검 **'에테르'**로 마왕을 봉인했다
- 봉인의 동력원은 **세계수 유그드의 마나**
- → 세계수가 마르면 봉인도 약해진다 (**멸망 원인들이 서로 연결되는 구조**)

| 항목 | 내용 |
|---|---|

## 7. 원작 지식 시스템 (게임 메커니즘)

### 📓 공략 노트
내가 기억하는 원작 정보를 정리한 노트. 항목마다 **출처 등급**이 있어요.

| 등급 | 출처 | 신뢰도 | 예시 |
|---|---|---|---|
| ★★★ | 직접 플레이 | 확실함 | "리아나는 2학년 여름 합숙에서 죽는다" |
| ★★ | 커뮤니티 공략 | 대체로 정확 | "그림은 황제 암살을 목격했다" |
| ★ | 데이터마이닝 | 불확실 | "핀의 검술 스탯이 S로 설정되어 있음" |
| ? | 루머 / 추측 | 반반 | "2황자가 진범이다" |

### 🦋 원작 붕괴도
- 원작 사건에 개입할 때마다 상승합니다 (0% ~ 100%)
- 붕괴도가 오르면 공략 노트 항목에 **"⚠️ 더 이상 신뢰할 수 없음"** 표시가 붙어요
- 붕괴도 구간별 효과:

| 붕괴도 | 효과 |
|---|---|
| 0~20% | 원작과 거의 같음. 노트를 그대로 믿어도 됨 |
| 21~50% | 사건 시기가 조금씩 앞당겨지거나 미뤄짐 |
| 51~80% | 원작에 없던 사건이 생기고, 일부 인물의 역할이 바뀜 (교주가 다른 사람이 될 수도 있음) |
| 81~100% | 공략 노트가 거의 쓸모없어짐. 대신 **진엔딩 단서**가 나타나기 시작함 |

> 붕괴도는 나쁜 것만이 아닙니다. 진엔딩을 보려면 **결국 원작을 크게 무너뜨려야** 해요. 문제는 **언제, 얼마나** 무너뜨리느냐입니다.

### 🕰️ 기억 풍화
- 시간이 지날수록 원작 기억이 흐려져요. 매년 ★★★ 정보 일부가 ★★로 떨어짐
- 대응 방법: 일기에 기록해두기, `완전기억` 재능, 주기적으로 노트 복습 (행동 슬롯 소모)
