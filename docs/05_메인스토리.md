## 2. 서장: 빙의 (입학 전 1개월)

### 오프닝
> 3,000시간째의 플레이. 37번째 배드 엔딩.
> *"그리고 세계는, 다시 처음으로."*
> 화면이 꺼지고, 낯선 천장이 보인다.

- 출신에 따라 눈을 뜨는 장소가 다르다 (평민 집 다락방 / 몰락 귀족 저택 / 벨모어 백작가 / 아카데미 근처 여관 / 숲속 오두막)
- 거울을 보는 장면에서 **캐릭터 생성 화면**으로 넘어감 (이 몸에 어떤 재능이 있는지 "확인하는" 연출)
- 첫 독백: *"…에테크잖아. 그것도 입학 한 달 전."*

### 몸 주인의 흔적
- 서랍 속 일기장. 마지막 장이 찢겨 있다
- 출신별로 **몸 주인이 사라진 이유**에 대한 첫 단서가 다르다 (`몸 주인의 잔재` 재능이 있으면 단서가 하나 더)

### 한 달 동안의 행동 (행동 8회)
가장 중요한 자원은 **시간**이다. 기연을 모두 챙길 수는 없다.

| 기연 | 행동 | 얻는 것 | 대가 / 딜레마 |
|---|---|---|---|
| **폐광의 붉은 뿌리** | 3회 | 체질 +8, `병약` 1단계 완화 | 폐광 마물과 전투 (첫 전투 튜토리얼) |
| **고서점의 마력 순환 비급** | 2회 | 마력 운용 스킬 즉시 습득 | ⚠️ 원작에서 아렌이 2학년에 얻는 기연. **가로채면 아렌이 약해짐** |
| **뒷골목 정보상 그림** | 2회 | 정보 루트 개방, 황제 암살 떡밥 | 돈이 듦 |
| **새벽 연무장의 소년** | 2회 | **핀 발견** | `데이터마이너` 또는 `마력 감응`이 있어야 의미를 앎 |
| **집안 정리** | 1~3회 | 출신별 고유 보상 (가문 빚 정리, 하인 관계 회복 등) | |
| **기초 훈련** | 1회 | 능력치 소폭 상승 | |

**악역 도련님(에드릭 벨모어) 출신 전용:** 원작의 에드릭은 하인을 학대하던 인물이다. 서장에서 하인들과의 관계를 바꾸지 않으면 1학년 5월에 아무도 경고해주지 않는다 (사망 플래그와 연결).

## 3. 1장: 신입생 (1학년)

### 3월: 입학
| 이벤트 | 내용 | 분기 / 선택 |
|---|---|---|
| **입학식** | 성검 '에테르'가 아렌에게 반응. 원작 명장면 | 원작대로 진행 (관찰만 가능). 내 몸에 이상한 떨림 (`이계의 영혼` 복선) |
| **반 배정 시험** | 실기 시험. 나는 실력과 무관하게 D반 배정 (원작의 엑스트라 자리) | 시험 중 **세라**가 실신 직전 → 도와주면 세라 구제 / 무시하면 원작대로 탈락 |
| **기숙사 배정** | 룸메이트 결정 | 출신별로 다름. 평민이면 브루노, 귀족이면 미라벨 오빠의 옛 친구 등 |
| **첫 수업 주간** | 시간표 선택 (수업 5과목 + 자율 슬롯) | 시간표가 1학기 내내 고정됨. 누구와 같은 수업을 듣는지가 결정됨 |

**복선:** 입학식 단상 뒤, 도서관 사서 노인이 성검을 바라보며 중얼거림 — *"또 시작이구나."*

### 4월: 동아리와 결투
| 이벤트 | 내용 | 분기 / 선택 |
|---|---|---|
| **동아리 박람회** | 검술부 / 마법 연구회 / 원예부 / 신문부 / 미궁 탐사부 중 가입 | 동아리마다 만나는 인물과 정보가 다름 (원예부 → 리아나, 신문부 → 소문 시스템) |
| **카이든 vs 아렌 결투** | 원작 명장면. 카이든이 평민 아렌을 도발 | 끼어들기 / 지켜보기 / 카이든 편 들기 → **아렌 성격 분기 첫 번째 계기**, 카이든 첫인상 |
| **에드릭의 괴롭힘** | 원작 악역 에드릭이 아렌을 괴롭힘 | 에드릭 출신이면 **내가 그 자리에 있다**. 괴롭힐지, 그만둘지 선택 |

### 5월: 미궁 실습
| 이벤트 | 내용 | 분기 / 선택 |

## 4. 2~4학년 개요

### 2장: 첫 번째 상실 (2학년)
- **전공 선택** (주전공 + 부전공)
- **봄:** 월광초 마지막 기회. 후배 입학 (내가 멘토가 됨, 새 숨은 인재 1명)
- **여름:** ⚔️ **리아나 갈림길** — 숲 합숙 중 마수 습격. 원작에서 리아나 사망
- **가을:** 세계수의 이슬 획득 기회 (리아나 생존 시 실바니엘 초대)
- **겨울:** 아렌에게 마력 순환 비급 기연 (서장에서 가로챘다면 아렌 성장이 정체됨)

### 3장: 가면들 (3학년)
- **봄:** 미궁 5~7층. 마기 결정 첫 획득 기회
- **여름:** ⚔️ **마탑 사건** — 미라벨 가문의 원수가 교단이었음이 드러남. 같은 주에 원작 리아나 루트 의식도 겹침 (주인공 혼자선 둘 다 불가능)
- **가을:** **내 잠재 재능 `이계의 영혼` 발현.** 성검이 나에게도 반응. 교회가 나를 주시
- **겨울:** 카엘의 정체가 교회에 의심받음. 심문을 막을지 선택

### 4장: 졸업 (4학년)
- **봄:** 비스톨 교수 갈림길 (구원 / 고발 / 방치)
- **여름:** ⚔️ **미라벨 갈림길** — 원수를 쫓아 실종되는 사건
- **가을:** 졸업 시험 = 실제 잿빛 장벽 전선 투입
- **겨울:** **진로 선택** (기사단 / 마탑 / 교회 / 용병 / 아카데미 조교 / 독자 세력). 진로에 따라 2부의 거점이 달라짐

## 7. 진엔딩으로 가는 핵심 진실 (작가용 메모)

> 플레이어에게는 마지막에만 공개되는 설정

1. 이 세계는 **10년마다 반복**된다. 멸망하면 처음으로 돌아간다
2. 반복의 원인은 천 년 전 초대 용사가 마왕을 봉인할 때 쓴 **에테르의 저주**. 봉인을 유지하기 위해 세계의 시간을 고리로 묶었다
3. 개발사 '망각'은 **이전 회차의 생존자**가 다른 세계에 남긴 흔적. 게임은 다음 회차의 누군가에게 보내는 공략서였다
4. 나(플레이어)가 빙의한 몸의 원래 주인은 **반복을 눈치챈 사람**이었고, 일기장의 찢긴 장에는 "바깥의 누군가를 부르는 방법"이 적혀 있었다
5. 마왕 이그니스는 단순한 악이 아니라, **반복을 끝내려고 봉인을 깨려는 존재**다. 방법이 파괴적일 뿐
6. 진엔딩: 6개 멸망 원인을 모두 해결한 상태에서, 마왕을 죽이지 않고 **에테르의 고리를 끊는다**. 세계는 처음으로 **11년째**를 맞는다
