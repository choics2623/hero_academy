# 03. 캐릭터 운명 분기 시스템

> 대화는 전부 **사전 작성 스크립트**로 만든다. 대신 **분기와 볼륨**으로 몰입감을 만든다.
> 내 선택에 따라 캐릭터의 운명이 갈라지고, 그 운명이 이후 스토리를 바꾼다.

---

## 1. 관계 수치

캐릭터마다 아래 수치를 따로 가진다.

| 수치 | 범위 | 보이는가 | 설명 |
|---|---|---|---|
| **호감도** | 0~100 (랭크 1~10) | 보임 | 얼마나 친한가. 10점마다 랭크 1 상승 |
| **신뢰** | -50~+50 | 숨김 | 나를 믿는가. 거짓말, 약속 파기, 비밀 누설로 하락 |
| **비밀 이해도** | 0~3단계 | 공략 노트에 표시 | 그 캐릭터의 숨겨진 사정을 얼마나 알고 있는가 |
| **마음 상태** | 태그 | 묘사로만 암시 | `불안` `질투` `원한` `희망` `집착` `체념` 등. 사건에 따라 붙었다 떨어짐 |

### 호감도와 신뢰는 다르다
- 선물 공세로 호감도는 올릴 수 있지만 **신뢰는 행동으로만** 오른다
- 호감도는 높은데 신뢰가 낮으면 → **"좋아하지만 믿지는 않는" 상태.** 위기 때 내 말을 듣지 않는다
- 호감도는 낮은데 신뢰가 높으면 → **"싫지만 인정하는" 라이벌 관계.** 카이든, 미라벨 초반이 대표적

### 비밀 이해도 단계
| 단계 | 의미 | 해금 방법 |
|---|---|---|
| 0 | 원작 지식으로만 앎 (본인은 내가 아는 줄 모름) | 시작 상태 |
| 1 | 단서를 직접 확인함 | 관찰 이벤트, 탐색, 원작에 없던 장면 목격 |
| 2 | 본인이 일부를 털어놓음 | 호감도 랭크 5 이상 + 신뢰 10 이상 + 특정 장소 이벤트 |
| 3 | 모든 사정을 공유함. **운명 분기 조건 충족** | 랭크 7 이상 + 신뢰 25 이상 + 위기 이벤트에서 내가 곁에 있었음 |

> ⚠️ **원작 지식으로 아는 비밀을 섣불리 말하면** 신뢰가 크게 떨어진다. "너 그걸 어떻게 알아?"
> 비밀은 **본인이 털어놓게 만들어야** 한다. 이게 빙의자 플레이의 핵심 긴장감이다.

## 2. 운명 분기 구조

모든 주요 캐릭터는 **원작 운명** 하나와 **분기 운명** 여러 개를 가진다.

```
                    ┌─ 각성 (원작보다 강해짐, 아군)
                    ├─ 타락 (강해지지만 위험. 적이 되거나 불안정한 아군)
원작 운명 ── 갈림길 ─┼─ 구원 (힘은 평범하지만 살아남고 행복해짐)
                    ├─ 이탈 (살아남지만 내 곁을 떠남. 후반 재등장)
                    └─ 원작대로 (사망 또는 원작 결말)
```

### 운명의 갈림길 (Crossroads)
- 캐릭터마다 **1~3개의 정해진 시기**에 갈림길 이벤트가 있다
- 갈림길에서 운명을 결정하는 것:
  1. **호감도 랭크**
  2. **신뢰**
  3. **비밀 이해도**
  4. **마음 상태** 태그
  5. **보유 아이템** (정수, 치료제, 유물)
  6. **그 시점에 내가 그 자리에 있는가** (행동 슬롯 선택)
- 갈림길을 놓치면 **원작대로** 흘러간다. 시간이 핵심 자원인 이유

### 같은 아이템, 다른 결과
**정수(精髓)** 계열 아이템은 사용하는 순간의 **신뢰와 마음 상태**에 따라 결과가 갈린다.

| 상황 | 결과 |
|---|---|
| 신뢰 높음 + 마음 상태 `희망` | **각성** |
| 신뢰 높음 + 마음 상태 `불안` | 각성하지만 부작용 (일시적 폭주) |
| 신뢰 낮음 + 마음 상태 `원한` 또는 `집착` | **타락** |
| 비밀 이해도 3 미만 | 사용 불가 ("이걸 왜 나한테…?" 거절) |

> 같은 **마기 결정**이라도, 나를 믿는 카엘에게 주면 마왕 혈통이 각성하고, 나를 원망하는 카엘에게 주면 마왕군 간부로 타락한다.

## 4. 주요 캐릭터 운명표

### 🗡️ 아렌 (원작 주인공)
| 운명 | 조건 | 결과 / 스토리 영향 |
|---|---|---|
| 원작대로 | 개입 없음 | 루트 하나만 해결. 동료가 죽으면 흑화 |
| **각성: 진정한 용사** | 신뢰 30+, 사망 동료 0~1명, 에테르 결정 | 성검 완전 각성. 마왕 결전 승률 크게 상승 |
| **타락: 마검의 용사** | 동료 2명 이상 사망 또는 내가 배신 | 최종 보스화. 진엔딩 불가 (회귀 엔딩으로) |
| **구원: 평범한 청년** | 아렌이 용사의 운명을 거부하도록 내가 설득 | 성검을 내려놓음. **내가 대신 용사가 되어야 함** (하드 루트) |
| **이탈: 방랑 기사** | 신뢰 마이너스 + 내가 성검 기연을 가로챔 | 아카데미를 떠남. 7년차에 원수로 재등장 |

**성격 분기** (1학년 동안 나와의 관계로 결정): `다정` `냉정` `오만` `겁쟁이`
- 성격에 따라 대사, 루트 선택 성향, 흑화 조건이 달라짐 (오만하면 흑화 조건이 완화됨)

|---|---|---|

| **가렌** | 5년차 장벽 전투 사망 | **생존**: 장벽 전투에 내가 참전 + 가렌의 옛 동료 정보 / **스승 각성**: 인연 MAX 시 비전 '마지막 일격' 전수 |
| **비스톨** | 교단 교주 | **구원**: 죽은 딸의 진실을 알려주고 교단에서 이탈시킴 / **고발**: 증거 수집 후 체포 / **방치**: 원작대로 |
| **시스터 루나** | 교회 숙청에 휘말려 사망 | **생존**: 세라 각성 루트와 연결 |
| **엘베라** | 마지막에 행방불명 | **진실**: 카엘 각성 + 엘베라 인연 MAX → 마왕과의 과거 공개 |

## 5. 운명이 스토리에 미치는 영향 (연쇄)

운명은 서로 연결되어 있다. 한 명을 구하면 다른 사건이 바뀐다.

```
리아나 구원 ──→ 아렌 흑화 게이지 감소
리아나 각성 ──→ 세계수 치유 ──→ 마왕 봉인 유지 기간 +2년
카이든 각성 ──→ 내전 회피 ──→ 브루노 사망 사건(수도 습격) 소멸
미라벨 타락 ──→ 차원문 2년 앞당겨짐 ──→ 핀 사망 시기도 앞당겨짐
카엘 각성 ───→ 마왕 부활의 진실 ──→ 엘베라 비밀 해금 ──→ 히든 엔딩 단서
핀 발견 ─────→ 가렌 교관과 사제 관계 ──→ 가렌 생존 루트 난이도 하락
```

- 운명 결과는 **이후 장면의 대사와 등장인물**에 반영된다
  - 예: 리아나가 살아 있으면 3학년 축제 장면에 리아나가 등장하고, 죽었으면 아렌이 리아나 자리를 보며 멈칫한다
- **분기 후 합류 원칙:** 큰 줄기(연표의 사건)는 대부분 그대로 일어나지만, **누가 그 자리에 있고 어떤 결과가 나는지**가 바뀐다. 이렇게 해야 분기가 폭발적으로 늘어나지 않는다

## 6. 복선 시스템

### 복선의 3종류
| 종류 | 설명 | 예 |
|---|---|---|
| **원작 복선** | 원작에도 있던 떡밥. 공략 노트로 이미 의미를 앎 | 리아나가 계단을 오르다 가슴을 짚는 장면 |
| **붕괴 복선** | 원작에 **없던** 장면. 붕괴도가 만든 새로운 흐름의 신호 | 원작엔 없던 검은 망토의 남자가 비스톨 교수와 대화 |
| **진실 복선** | 원작 플레이어도 몰랐던 진엔딩 떡밥 | 도서관 사서가 천 년 전 지명을 현재형으로 말함 |

### 복선 발견
- 장면 속 특정 묘사는 **관찰 판정**(지성, 직감, 마력 감응)에 성공해야 공략 노트에 기록된다
- 놓친 복선은 나중에 회상 장면에서 "그러고 보니…"로 다시 보여줌 (일부만)
- 공략 노트의 **복선 탭**에 "회수됨 / 미회수" 상태로 정리

### 연출 원칙
- 원작에 없던 장면이 나오면 화면에 작은 **⚠ 원작 이탈** 아이콘
- 내면 독백으로 원작과 비교: *"원작에서 이 자리엔 아무도 없었는데."*

## 7. 볼륨을 키우기 위한 제작 방식

대화와 이벤트를 **코드가 아니라 데이터로** 작성한다. 그래야 스토리 분량을 늘려도 개발이 무너지지 않는다.

### 이벤트 데이터 예시
```yaml
id: liana_y1_stairs
title: 계단의 리아나
when: { year: 1, month: 6, slot: afternoon, place: east_stairs }
requires:
  affinity.liana: ">= 20"
foreshadow: liana_heart          # 복선 ID
check: { stat: 지성, or_talent: 직감, dc: 30 }
scenes:
  - speaker: 리아나
    text: "아, 괜찮아. 계단이 좀 가팔라서 그래."
  - inner: "(원작에서 이 장면, 2년 뒤를 암시하는 거였지.)"
choices:
  - text: "보건실 같이 가자."
    effects: { affinity.liana: +3, trust.liana: +2 }
  - text: "월광초라는 약초 알아?"
    requires: { note: liana_heart_cure }
    effects: { trust.liana: -5, mood.liana: 불안, secret.liana: 1 }
    next: liana_suspicious        # "그걸 어떻게 알아?"
  - text: (모른 척한다)
    effects: {}
```

### 분량 목표 (초안)
| 항목 | 1학년 (MVP) | 전체 |
|---|---|---|
| 메인 스토리 이벤트 | 30 | 200+ |
| 캐릭터 인연 이벤트 | 캐릭터당 5 (랭크 1~5) | 캐릭터당 10 + 운명별 엔딩 |
| 랜덤 / 일상 이벤트 | 60 | 400+ |
| 갈림길 이벤트 | 4 | 30+ |
| 복선 | 15 | 80+ |
