# 08. 판정 · 특성 · 기억의 파편 · 회귀 · 장비

특성 조합과 능력치가 선택의 성패를 가르고, 빙의자는 「기억의 파편」으로 미래를 엿보며,
죽으면 그 달 1주차로 돌아간다. 가방과 장비 8칸이 판정과 전투를 거든다.

---

## 1. 판정 (content/checks.yaml)

선택지마다 공식을 따로 쓰지 않는다. **판정 종류**를 한 곳에 정의하고, 선택지는 종류와 난이도만 적는다.

```yaml
types:
  - id: 설득
    icon: talk                      # 16px 아이콘 (src/art/icons.ts)
    value: "stat.매력 + stat.지성 / 2"
    desc: 말로 마음을 움직인다
    plus:  { 달변: 5, 사람좋은얼굴: 3, 미모: 2 }   # 재능 id → 보너스
    minus: { 말더듬: 5, 혐오스러운분위기: 4 }      # 재능 id → 감점
```

- `plus`/`minus`의 키는 `talent.` 뒤에 붙는 이름이다. 선택형 재능은 `서번트.검`처럼 쓴다.
- 판정 값 = 기본 공식 + 재능 보정 + 시너지 보정 + 장비 보정 + 상황 보정(mods) + `luck`.
- 성공: 값 + d20 ≥ 난이도.

### 선택지에 쓰는 법
```yaml
choices:
  - text: 사서를 설득해 금서 서가 열쇠를 빌린다
    check:
      type: 설득
      dc: 어려움                  # 쉬움 / 보통 / 어려움 / 극한  (또는 숫자)
      mods:                       # 상황 보정 (선택)
        - { when: "origin == '몰락귀족'", value: 3, label: 귀족 예법 }
        - { when: "affinity.librarian >= 30", value: 2, label: 사서와의 친분 }
    success: { lines: [...], effects: [...] }
    fail:    { lines: [...] }
    great:   { lines: [...], effects: [...] }   # 대성공일 때 success 뒤에 덧붙음 (선택)
    fumble:  { lines: [...], effects: [...] }   # 대실패일 때 fail 뒤에 덧붙음 (선택)
```

- 난이도 이름은 달이 갈수록 자동으로 오른다 (능력치가 자라므로). 숫자 난이도는 그대로 쓴다.
  - 기준(3월): 쉬움 26 · 보통 31 · 어려움 36 · 극한 42. 4월 +3, 5월 +6, 6월 +9, 7월 +12. 서장(2월) −1.
  - 한 능력치만 몰아 키워 그 달 기대치보다 8 넘게 높으면 넘친 부분은 35%만 친다 (softcap).
  - 평범한 캐릭터 기준 확률: 쉬움 ≈ 80% · 보통 ≈ 55% · 어려움 ≈ 30% · 극한 ≈ 5%.
  - 해당 분야에 몰아준 캐릭터는 보통을 거의 확실히 넘는다. 이게 "빌드가 먹히는" 순간이다.
- 대성공: 주사위 20, 또는 목표를 10 이상 넘김. 대실패: 주사위 1, 또는 목표에 10 이상 못 미침.
- `hidden: true`면 주사위 연출 없이 결과만 흐른다 (몰래 굴리는 판정).
- 옛 형식 `check: { value: 식, dc: 숫자, label: ... }`도 그대로 동작한다. 새로 쓰는 판정은 종류를 쓴다.

### 화면에 보이는 것
- 고르기 전: `설득 · 유리` + 작용하는 요인 최대 3개 (`달변▲ 말더듬▼ 귀족 예법▲`).
  - 확률 말: 확실(90%↑) · 유리(65%↑) · 반반(40%↑) · 불리(15%↑) · 무모.
- 굴린 뒤: 주사위와 함께 결정적이었던 요인 ("달변 덕분에!" / "말더듬이 발목을 잡았다").

### 어떤 선택지에 판정을 붙이나
- **시도형** (설득, 싸움, 잠입, 거짓말, 구조, 공부, 버티기, 손재주…): 판정을 붙이고 성공·실패를 둘 다 쓴다.
- **결심형** (누구와 갈지, 어디로 갈지, 무엇을 말할지): 판정 없이 둔다.
  대신 특성이 있으면 반응이 달라지게 조건부 대사나 `branch`를 쓴다 (예: 자연친화력이면 고양이가 따라온다).
- 실패도 이야기다. 실패 결과는 "아무 일 없음"이 아니라 다른 장면이어야 한다 (6–15줄).

## 2. 특성 (talents.yaml, synergies.yaml)

### 태그
재능마다 `tags`를 붙인다: 검 · 마법 · 신성 · 사교 · 은밀 · 학자 · 야생 · 강인 · 저주.
```yaml
- { id: 달변, name: 달변, cost: 3, category: 사회, tags: [사교], desc: "...", effects: [...] }
```

### 시너지 (컨셉 보너스)
같은 태그를 가진 재능이 모이면 컨셉이 깨어난다. 출신 기본 재능도 센다. 진화로 얻은 재능도 센다.
```yaml
- id: 사교가
  tag: 사교
  tiers:
    - { need: 2, desc: "설득·기만 +2", checks: { 설득: 2, 기만: 2 } }
    - { need: 3, desc: "설득·기만 +4, 전투 설득 +4", checks: { 설득: 4, 기만: 4 }, battle: { persuade: 4 } }
```
- 이벤트 조건에서 `synergy.사교가` (0, 1, 2 = 단계)로 읽는다. 시너지 전용 선택지를 만들 수 있다.

## 3. 빙의자 기본기 (특전 폐지)

캐릭터 생성의 "빙의자 특전" 선택은 없앴다. 3,000시간 고인물이라면 당연한 것들은 기본이다.
- `perk.고인물의기억`, `perk.공략위키편집자`, `perk.데이터마이너`는 언제나 1 (원작 지식, 위키, 데이터).
- 상태창 · 감정안은 없다 (능력치는 말과 화살표로 본다). 최적 동선은 일반 재능이 되었다.
- 새 대사에서 `perk.*` 조건은 쓰지 않는다. 원작 지식은 그냥 속마음으로 쓴다.

## 4. 기억의 파편

빙의자가 3,000시간의 기억을 더듬어 앞일을 본다. 변수 `shard` (최대 `shard.max` = 3).
- 얻는 법: 시작 1개 · 매달 말 +1 · 갈림길을 원작과 다르게 바꿀 때 +1 · 콘텐츠의 큰 순간 `shard += 1`.
- 쓰는 법: 선택지나 활동 칸 앞에서 1개 → 각 선택지의 미래가 열린다.
  - 판정 확률(%), 성공·실패 각각에 얻는 것 (능력치 ▲, 호감 ♥, 물건, 재능, 기술, 노트), 이어지는 사건 제목, 운명의 변화, 전투.
  - 활동 칸: 이번 칸에 그 활동을 하면 실제로 벌어질 일.
- 한 번 본 미래는 기억된다. **죽고 돌아와 같은 자리에 오면 무료로 다시 보인다.**
- `veiled: true`를 단 선택지는 "기억에 없는 일"로만 보인다. 반전을 지켜야 할 때만 쓴다.

## 5. 죽음과 회귀

- 결과의 효과에 `death = '원인'`을 넣으면 그 장면의 대사가 끝난 뒤 죽는다. 원인은 띄어쓰기 없이 (`'폐광붕괴'`).
  ```yaml
  fumble:
    lines: [ "발밑이 꺼졌다.", "……", "차갑다." ]
    effects: [ "death = '폐광붕괴'" ]
  ```
- 죽으면 화면이 꺼지고 **그 달 1주차 첫 칸**(자동 저장)으로 돌아간다.
  그 달의 성장·호감·사건은 되돌아가지만, 기억은 남는다:
  - 회귀 횟수 `loop.count`, 죽은 원인 `died.<원인>` = 1 (예: `died.폐광붕괴`), 방금 돌아왔으면 `loop.just` = 1.
  - 기억의 파편으로 본 미래는 무료로 다시 보이고, 지난 생에서 고른 선택지에는 표시가 붙는다.
- 돌아온 직후 장면: `on: auto`, `when: "loop.just"`, `free: true` 인 이벤트가 뜬다. 효과에 반드시 `loop.just = 0`.
- 죽음은 **예고된 위험**에서만: 무모한 판정의 대실패, 혼자 싸워 진 위험한 전투, 경고를 무시한 선택.
  직감 재능이나 속마음이 미리 경고해야 한다. 억울한 죽음은 없다.

## 6. 가방과 장비 (content/items.yaml)

```yaml
- id: 가죽장화
  name: 가죽 장화
  slot: 신발            # 모자 · 윗옷 · 아래옷 · 한벌옷 · 장신구 · 무기 · 신발 (없으면 장착 불가)
  kind: equip           # equip(장비) · use(소모품) · key(귀중품)
  icon: boots           # hat shirt pants robe ring amulet sword staff boots potion herb book letter charm misc
  price: 12             # 상점 가격 (없으면 상점에 안 나옴)
  desc: 밑창을 두 번 기운 장화. 발소리가 작다.
  checks: { 은밀: 1, 기민: 1 }      # 판정 보정
  battle: { def: 0.5 }              # 전투 보정: hp sp mp atk matk def dodge read persuade
  use: [ "fatigue -= 20" ]          # 소모품: 가방에서 쓰면 적용 (kind: use)
```
- 장비 칸: 모자 · 윗옷 · 아래옷 · 한벌옷 · 장신구 2개 · 무기 · 신발. 한벌옷은 윗옷과 아래옷 칸을 함께 쓴다.
- 갖고 있는 수: `item.<id>`. 장착: `equip.<칸>` (장신구는 `equip.장신구1`, `equip.장신구2`).
- 얻는 법: 결과 효과에 `item.<id> += 1`. 상점은 선택지로 (`requires: "money >= 12"`, 효과 `money -= 12`).
- 이벤트 조건에서 `item.월광초 >= 1`, `equip.무기 == '브루노목검'`처럼 읽는다.
- 선물받은 장비를 차고 있으면 그 사람의 대사가 달라지면 좋다.
