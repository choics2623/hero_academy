# 04. 재능 개화 & 스킬트리

---

## 1. 성장의 세 축

| 축 | 무엇 | 어떻게 오르나 |
|---|---|---|
| **능력치** | 근력, 마력량 등 8개 | 수업, 훈련, 토벌 |
| **재능** | 타고난 소질 (02 문서) | **개화**: 조건을 달성하면 단계가 오름 |
| **스킬** | 실제로 쓰는 기술 | **스킬트리**: 스킬 포인트(SP)로 습득 |

---

## 2. 재능 개화

### 개화 단계
모든 양수 재능은 4단계로 성장한다.

| 단계 | 이름 | 의미 |
|---|---|---|
| 0 | **잠재(潛在)** | 가지고 있지만 아직 모름. 숨겨진 재능 |
| 1 | **발현(發現)** | 기본 효과. 캐릭터 생성 시 고른 재능은 여기서 시작 |
| 2 | **개화(開花)** | 효과 강화 + 새 능력 추가 |
| 3 | **만개(滿開)** | 그 재능의 정점. 고유 능력 해금 |

### 개화 조건 유형
- **숙련:** 관련 행동을 일정 횟수 이상 (예: 마법 수업 30회)
- **능력치:** 관련 능력치 기준 달성
- **사건:** 특정 이벤트 경험 (위기, 패배, 깨달음)
- **인연:** 특정 스승이나 동료와의 랭크
- **아이템:** 영약, 정수

### 주요 재능 개화표
| 재능 | 발현 | 개화 (조건 → 효과) | 만개 (조건 → 효과) |
|---|---|---|---|
| **마나 탱크** | 마력량 +20 | 마력량 60 → **마나 순환**: 전투 중 매 턴 MP 회복 | 마력량 90 + 세계수 성역 방문 → **마나의 바다**: 동료에게 MP 공유 |
| **강골** | 부상 -30% | 부상 상태로 훈련 20회 → **철골**: 골절 무효 | 근력 80 + 용의 심장 정수 → **용골(龍骨)**: 방어력 대폭 상승, 넉백 무효 |
| **질긴 힘줄** | 피로 -20% | 훈련 100회 → **지치지 않는 몸**: 하루 행동 슬롯 +1 (주 2회) | 체질 80 → **무한 지구력**: 장기전 패널티 무효 |
| **만독불침** | 독 면역 | 독 30종 섭취 → **독을 먹는 자**: 독을 섭취하면 일시 강화 | 이독제독 시너지 + 연금 B → **만독지체(萬毒之體)**: 내 피가 해독제가 됨 (동료 치료) |
| **마도학 재능** | 이론 수업 +30% | 술식 분석 50회 → **술식 해체**: 적 마법 무효화 확률 | 지성 85 + 엘베라 인연 MAX → **신규 술식 창조**: 나만의 마법 설계 |
| **자연 친화력** | 동물·정령 호감 | 정령 계약 1회 → **정령 대화**: 숲에서 정보 수집 | 리아나 각성 + 세계수 성역 → **숲의 대변자**: 세계수와 교감 |
| **마력 감응** | 재능 '느낌' 감지 | 숨은 인재 3명 발견 → **재능 투시**: 숨은 재능 이름까지 보임 | 숨은 인재 6명 각성 → **운명 감지**: 동료의 갈림길 시기가 공략 노트에 표시됨 |
| **천생신력** | 근력 +15 | 근력 70 → **괴력난신**: 대형 무기 한 손 사용 | 강철 육체 시너지 → **산을 쪼개는 자**: 궁극기 해금 |
| **강철 멘탈** | 스트레스 -40% | 공포 판정 30회 성공 → **부동심**: 정신 공격 면역 | 의지 90 → **불멸의 의지**: 동료 전원 공포 면역 오라 |
| **직감** | 위험 경고 | 경고 무시 후 위기 극복 10회 → **예지**: 갈림길 이벤트 하루 전 예감 | 운 판정 극복 → **운명 엿보기**: 중요 선택지의 결과 일부 미리보기 |
| **성흔** | 신성력 사용 | 치유 100회 → **성광**: 언데드·마기 피해 2배 | 성녀의 눈물 → **기적**: 사망한 동료 1명 부활 (게임당 1회) |
| **완전기억** | 기억 풍화 없음 | 책 50권 열람 → **속독**: 도서관 행동 효율 2배 | 해독자 시너지 → **세계의 기록**: 진엔딩 단서 자동 해석 |

### 잠재 재능 (숨겨진 재능)
- 모든 캐릭터는 **1~2개의 잠재 재능**을 가지고 태어난다. 나도 마찬가지
- 생성 화면에서는 보이지 않고, 조건을 만족하면 "발현" 이벤트가 일어남
- 예시:
  - **나의 잠재 재능 (모든 출신 공통)**: `이계의 영혼` — 원작 시스템 밖의 존재라서 **운명 보정을 받지 않는다**. 3학년에 발현. 진엔딩의 열쇠
  - **핀:** `검재(劍才)` 잠재 → 트라우마 극복 시 발현
  - **아렌:** `에테르 공명` 잠재 → 성검 각성 시 발현
  - **도로시:** `연금 서번트` 잠재 → 아카데미 청강 시작 시 발현

## 3. 스킬 포인트 (SP)

| 획득 방법 | SP |
|---|---|
| 과목 수료 (학기말) | 과목당 1 |
| 시험 우수 성적 | 1~2 |
| 토벌 / 던전 클리어 | 1~3 |
| 인연 랭크 5, 10 달성 | 1 / 2 |
| 재능 개화 / 만개 | 2 / 3 |
| 기연 (비급서 등) | 해당 스킬 즉시 습득 |

- 1학년 동안 약 **12~15 SP**, 4년간 약 **60 SP**
- 모든 트리를 다 찍을 수 없다. **나는 일부만 찍고, 나머지는 동료가 맡는 구조**

---

## 4. 스킬트리 구조

```
[1학년] 공통 기초 트리 (전원)
          │
[2학년] 전공 트리 선택 (주전공 1 + 부전공 1)
   ├─ 기사과: 검술 트리
   ├─ 마도과: 마법 트리
   ├─ 신성과: 신성 트리
   ├─ 레인저과: 레인저 트리
   └─ 연금과: 연금 트리
          │
[3학년] 상위 분화 (각 트리 안의 세 갈래 중 하나에 집중)
          │
[4학년~] 숨은 트리 / 합성 스킬 / 스승 비전
```

- 각 갈래는 **1~5단계**. 단계마다 능력치 조건이 있음
- **주전공**은 5단계까지, **부전공**은 3단계까지만 찍을 수 있음
- 스킬 종류: 🔷 액티브 / 🔶 패시브 / ⭐ 궁극기 (5단계)

## 5. 공통 기초 트리 (1학년)

| 스킬 | 종류 | SP | 효과 |
|---|---|---|---|
| 기초 검술 | 🔷 | 1 | 기본 베기, 막기 |
| 기초 마력 운용 | 🔶 | 1 | 마법 수업 효율 +10% |

| 마물학 기초 | 🔶 | 1 | 적 약점 표시 |
| 협동 전투 | 🔶 | 2 | 파티원과 합체기 사용 가능 (인연 랭크 조건) |

## 6. 전공 트리

### ⚔️ 검술 트리 (기사과)
| 단계 | 수호의 검 | 공격의 검 | 마검 |
|---|---|---|---|
| 1 | 🔷 방패 막기 | 🔷 연속 베기 | 🔶 검에 마력 두르기 |
| 2 | 🔶 철벽 (방어 +) | 🔷 찌르기 돌진 | 🔷 속성 부여 (원소 친화 연동) |
| 3 | 🔷 대신 맞기 (동료 보호) | 🔶 약점 간파 | 🔷 검기 날리기 (원거리) |
| 4 | 🔶 불굴의 진형 (파티 방어 +) | 🔷 일섬 (고위력 단일기) | 🔶 마력 검신 (검 길이 연장) |
| 5 | ⭐ **성벽** — 3턴간 파티 피해 무효 | ⭐ **천검** — 무수한 검격 | ⭐ **마검 해방** — 마력 전부를 한 번의 베기에 |

### 🔮 마법 트리 (마도과)
| 단계 | 원소 | 제어 | 결계 |
|---|---|---|---|
| 1 | 🔷 원소 화살 | 🔶 영창 단축 | 🔷 마력 방벽 |
| 2 | 🔷 원소 폭발 (범위) | 🔷 마법 반사 | 🔶 결계 지속 + |
| 3 | 🔶 원소 융합 (두 속성 조합) | 🔷 마력 흡수 | 🔷 봉인술 (적 스킬 봉인) |
| 4 | 🔷 대마법 (강력, 영창 2턴) | 🔶 이중 영창 | 🔷 공간 결계 (전장 지형 변경) |
| 5 | ⭐ **원소 재앙** | ⭐ **시간 지연** (적 행동 1턴 정지) | ⭐ **차원 봉쇄** — 차원문 봉쇄의 필수 스킬 |

### ✝️ 신성 트리 (신성과)
| 단계 | 치유 | 정화 | 심판 |
|---|---|---|---|
| 1 | 🔷 치유의 손 | 🔷 해독 | 🔷 빛의 화살 |
| 2 | 🔷 광역 치유 | 🔷 저주 해제 | 🔶 언데드 특효 |
| 3 | 🔶 재생 (지속 회복) | 🔷 마기 정화 | 🔷 신벌 (마족 특효) |
| 4 | 🔷 소생 (전투 불능 회복) | 🔶 정화의 오라 | 🔷 성역 선포 |
| 5 | ⭐ **기적의 빛** | ⭐ **영혼 정화** — 타락한 동료를 되돌림 (조건부) | ⭐ **최후의 심판** |

> ⚠️ **영혼 정화**는 타락한 동료를 구원할 수 있는 거의 유일한 수단. 단, 신뢰가 0 이상 남아 있어야 함

### 🏹 레인저 트리 (레인저과)
| 단계 | 궁술 | 추적 | 생존 |
|---|---|---|---|
| 1 | 🔷 조준 사격 | 🔶 발자국 읽기 | 🔶 채집 효율 + |
| 2 | 🔷 연사 | 🔷 함정 설치 | 🔷 약초 조합 |
| 3 | 🔶 급소 사격 | 🔷 은신 | 🔶 지형 활용 |
| 4 | 🔷 관통 화살 | 🔶 기습 (선제 공격 확정) | 🔷 야생 동료 소환 (자연 친화력 필요) |
| 5 | ⭐ **천공의 화살** | ⭐ **그림자 사냥꾼** | ⭐ **숲의 수호자** |

### ⚗️ 연금 트리 (연금과)
| 단계 | 포션 | 독 | 공학 |
|---|---|---|---|
| 1 | 🔷 회복약 제조 | 🔷 마비독 | 🔷 연막탄 |
| 2 | 🔷 강화약 | 🔶 독 내성 + | 🔷 폭탄 |
| 3 | 🔶 대량 제조 | 🔷 맹독 칼날 | 🔶 장비 개조 |
| 4 | 🔷 영약 제조 (운명 아이템 일부 제작 가능) | 🔷 독무 (범위) | 🔷 골렘 제작 |
| 5 | ⭐ **현자의 돌 (불완전)** | ⭐ **만독의 비술** | ⭐ **마도 공학 병기** |

> 연금 트리 포션 4단계가 있으면 **월광초 탕약**, **정화수**를 직접 만들 수 있음 → 리아나 구원 루트가 쉬워짐

## 7. 숨은 트리 (조건 해금)

| 트리 | 해금 조건 | 특징 |
|---|---|---|
| **투기(鬪氣)** | 마나 회로 손상 또는 강철 육체 시너지 | 마법 대신 생명력을 무기로. 맨손·대검 특화 |
| **단전(丹田) 무공** | 마나 회로 손상 + 강철 멘탈 | 원작 미구현 동방 무술. 경공, 내공, 점혈 |
| **정령술** | 자연 친화력 개화 + 정령 계약 | 정령 소환, 자연 마법 |
| **드루이드** | 숲의 아이 시너지 | 변신 (늑대, 곰, 매) |
| **마기(魔氣)** | 마왕의 흔적 + 카엘 인연 5 | 마족의 힘. 강력하지만 교회 적대 |
| **독술** | 독의 현자 시너지 | 독을 다루는 암살 계열 |
| **에테르** | 이계의 영혼 발현 + 초대 용사 인연 MAX | 진엔딩 전용. 성검 없이 에테르를 다룸 |

## 8. 합성 스킬 (크로스 트리)

서로 다른 트리의 스킬 두 개를 3단계 이상 가지고 있으면 **합성 스킬**을 배울 수 있다.

| 조합 | 합성 스킬 | 효과 |
|---|---|---|
| 마검 3 + 원소 3 | **염룡참(炎龍斬)** | 화염 속성 범위 베기 |
| 치유 3 + 포션 3 | **성수 제조** | 신성 회복약 대량 생산 |
| 결계 3 + 추적 3 | **결계 함정** | 적을 결계 안에 가둠 |
| 투기 3 + 수호의 검 3 | **금강불괴** | 1턴 무적 |
| 독 3 + 은신 3 | **그림자 독침** | 암살 일격 |
| 정령술 3 + 치유 3 | **생명의 정령** | 세계수 치유 의식 보조 |

## 11. 숙련도와 스킬 변형

- 스킬은 사용할수록 숙련도가 오르고, **숙련 MAX에서 변형 하나를 선택**한다
- 예: **원소 화살** → `연사형` (3발, 위력↓) / `저격형` (1발, 위력↑↑, 영창 +1턴) / `유도형` (확정 명중)
- 같은 스킬도 캐릭터마다 다른 모습으로 자란다 → 내 캐릭터만의 개성
