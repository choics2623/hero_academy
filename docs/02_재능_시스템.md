## 1. 기본 능력치

| 능력치 | 의미 | 주로 영향을 주는 것 |
|---|---|---|
| **근력** | 힘, 무기 위력 | 검술, 근접 전투, 운반 |
| **민첩** | 속도, 반사신경 | 회피, 선공, 활, 은신 |
| **체질** | 체력, 회복력, 지구력 | 최대 HP, 피로 회복, 질병 저항 |
| **마력량** | 마나 총량 | 최대 MP, 대규모 마법 |
| **마력제어** | 마나를 다루는 정밀함 | 마법 성공률, 폭주 방지, 연금술 |
| **지성** | 학습력, 분석력 | 수업 효율, 술식 분석, 퍼즐 |
| **의지** | 정신력, 용기 | 스트레스 저항, 공포 판정, 각성 |
| **매력** | 호감, 설득력 | 첫인상, 인연 상승량, 교섭 |

- 수치 범위: 0 ~ 100 (일부 재능으로 상한 돌파 가능)
- 1학년 평균: 10 ~ 20 / 원작 주인공 졸업 시점: 주력 능력치 70 전후
- **등급 표기:** F(0~9) E(10~19) D(20~34) C(35~49) B(50~64) A(65~79) S(80~94) SS(95+)

### 숨은 수치
| 수치 | 설명 |
|---|---|
| 피로 | 행동할 때마다 쌓임. 높으면 효율이 떨어지고 부상 확률이 오름 |
| 스트레스 | 실패, 갈등, 트라우마로 쌓임. 한계를 넘으면 번아웃 이벤트 |
| 운 | 랜덤 판정 보정. 대부분의 재능으로는 바꿀 수 없음 |

## 2. 캐릭터 생성 흐름

```
① 빙의할 몸(출신) 선택 → ② 빙의자 특전 1개 선택 (무료)
→ ③ 재능 선택 (포인트 분배) → ④ 외형 / 이름 / 성격(말투) → ⑤ 입학 1개월 전부터 시작
```

### ① 출신 선택
| 출신 | 기본 포인트 | 기본 소지 재능 | 특징 |
|---|---|---|---|
| 평민 장학생 | 12 | 없음 | 자유롭지만 귀족에게 무시당함. 장학금 유지 조건 있음 |
| 몰락 귀족 3남 | 10 | 귀공자의 품격 | 가문 빚 이벤트. 귀족 사회 접근 가능 |
| **원작 1권에서 죽는 악역 도련님** | 6 | 악명 높은 가문 | 시작 평판 최악. 1학년 1학기 사망 플래그를 꺾어야 함. 대신 돈이 많음 |
| 이름 없는 엑스트라 | 15 | 없음 | 아무도 주목하지 않음. 원작 사건 개입 시 붕괴도 증가 -20% |
| 숲 출신 고아 | 11 | 자연 친화력 | 엘프 호감. 귀족 예법 판정 패널티 |

### ② 빙의자 특전 (1개 무료, 추가는 포인트 소모)
| 특전 | 추가 비용 | 효과 |
|---|---|---|
| 고인물의 기억 | +3 | 공략 노트 ★★★ 항목이 많은 상태로 시작. 기억 풍화 -50% |
| 데이터마이너 | +3 | 미구현 데이터 정보 해금 (숨은 인재 2명 + DLC 단서) |
| 공략 위키 편집자 | +3 | 기연(영약, 비급, 유물)의 위치와 획득 조건을 정확히 앎 |
| 최적 동선 | +3 | 매주 행동 슬롯 1개 추가 (스피드러너의 습관) |
| 상태창 | +2 | 내 능력치를 **정확한 숫자**로 볼 수 있음 (없으면 "꽤 강해진 것 같다" 같은 묘사로만 표시) |
| 감정안(鑑定眼) | +4 | 다른 사람의 능력치와 재능을 볼 수 있음 (숨은 재능은 인연 랭크 3 이상에서 보임) |

> **상태창**은 일부러 비용이 낮아요. 숫자 없이 묘사만으로 플레이하면 몰입감이 커지고, 숫자로 보면 최적화 플레이가 편해져요. 플레이 스타일 선택입니다.

### ③ 재능 선택 규칙
- **양수 재능(+)**: 포인트를 소모해서 획득
- **음수 재능(−)**: 획득하면 포인트를 돌려받음
- 음수 재능으로 얻는 포인트는 **최대 12점**까지 (과도한 조합 방지)
- 재능은 **최대 8개**까지 (출신 기본 재능 포함)
- 남은 포인트는 1점당 **능력치 +2**로 자유 분배 가능
- **등급:** 일반(1~2점) / 고급(3~4점) / 희귀(5~6점) / 전설(7점 이상, 회차 해금)

## 5. 재능 진화 (극복 시스템)

음수 재능은 **극복하면 양수 재능으로 바뀝니다.** 나쁜 재능을 가진 캐릭터가 성장하는 과정 자체가 스토리예요.

| 원래 재능 | 극복 조건 | 진화 결과 |
|---|---|---|
| 병약 | 체질 50 달성 + 앓아누운 횟수 10회 이상 | **불굴(不屈)**: 체질 성장 +20%, HP 1 이하로 떨어져도 1회 버팀 |
| 겁쟁이 | 강적 앞에서 도망치지 않은 횟수 5회 | **용기**: 공포 저항, 위기 시 능력치 + |
| 트라우마 | 관련 인연 이벤트 완료 + 해당 상황에서 승리 | **각성**: 그 원소의 친화 재능을 얻음 (불 트라우마 → 화염 친화) |
| 혐오스러운 분위기 | 의지 60 + 인연 랭크 MAX 캐릭터 3명 | **패왕의 기운**: 위압 대폭 +, 첫인상 패널티를 끄고 켤 수 있음 |
| 마력 폭주 체질 | 마력제어 50 + 엘베라 교수 인연 이벤트 | **폭풍의 마력**: 감정이 고조되면 마법 위력 +50% |

## 8. 동료도 같은 재능 시스템을 씀

- 원작 캐릭터와 숨은 인재도 **같은 재능표**를 가지고 있어요
- 예: **핀** — `천생신력` `고양이 반사신경` `서번트(검)` / `트라우마(피)` `게으름` `눈치 없음`
  - 트라우마 때문에 원작에서는 검을 잡지 못했음 → **내가 트라우마 극복을 도와주면 검성(劍聖)으로 각성**
- 원작 사망 캐릭터는 대개 **치명적인 음수 재능 하나**가 사망 원인과 연결되어 있어요
  - 예: 리아나의 `허약한 심장` → 2학년 합숙 전투가 길어지면서 사망
  - 내가 미리 알고 그 재능을 극복시키거나, 전투를 짧게 끝낼 수 있도록 대비하면 생존

## 9. 밸런스 원칙

1. **음수 재능은 반드시 극복 경로가 있다.** 플레이어를 괴롭히기만 하는 재능은 없다
2. **양수 재능만 고른 캐릭터는 무난하지만 평범하다.** 숨은 시너지 대부분은 음수 재능이 들어가야 열린다
3. **원작 지식 특전과 전투 재능은 경쟁 관계.** 정보에 투자할수록 내 몸은 약하고, 동료를 키워야 할 이유가 커진다
4. 수치는 프로토타입에서 플레이테스트로 계속 조정한다
